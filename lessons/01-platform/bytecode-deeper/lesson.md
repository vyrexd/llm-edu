# Углубление. Как JVM проходит условие

Дополнительная практика на 8–12 минут. Студент читает код и связывает условие Java с переходом и изменениями стека операндов. Он может сказать «Дальше по курсу» на любом шаге. Для возвращения прочитай `python3 course.py status` и открой текущую обязательную карточку.

## Что такое стек операндов

Начни с теории. Вызов метода создаёт кадр со своими локальными переменными и стеком операндов. Например, у статического метода `doubleValue(int)` аргумент находится в локальной переменной с индексом 0. `iload_0` кладёт её значение на стек, `iconst_2` кладёт число 2, `imul` забирает два числа и кладёт произведение, а `ireturn` возвращает верхнее значение вызывающему коду. Предложи проследить стек для аргумента 7.

## Как увидеть условный переход

Открой [BranchDemo.java](BranchDemo.java). Предложи по коду предсказать три строки вывода и дождись ответа. Затем из корня проекта действительно запусти:

```sh
mkdir -p .java-course/bytecode-deeper
javac -d .java-course/bytecode-deeper lessons/01-platform/bytecode-deeper/BranchDemo.java
java -cp .java-course/bytecode-deeper BranchDemo
javap -classpath .java-course/bytecode-deeper -c BranchDemo
```

Покажи вывод программы и только блок метода `absolute`. Попроси найти условный переход и проследить оба пути для `-3` и `5`. Если `javac` сгенерировал `ifge`, объясни, что он забирает число со стека и переходит к указанному смещению, если оно больше или равно нулю. Смещение бери из фактического вывода. При другом варианте компиляции объясняй фактическую инструкцию.

## Исправь метод и сравни программы

Попроси изменить `absolute`, чтобы он возвращал абсолютное значение для трёх заданных чисел. Вызовы в `main` остаются частью проверки. Дождись «Проверить». Выполни те же команды. Проверь вывод `3`, `0`, `5` и покажи, какие инструкции в ветке отрицательного значения изменились. При ошибке прочитай файл и дай одну подсказку.

Попроси студента объяснить, какая инструкция проверяет условие и какая меняет знак в его реализации. Если он использовал `Math.abs` или тернарный оператор, разбери фактический результат. Для упражнения в чтении перехода предложи сохранить исходное `if` и изменить только ветку для отрицательного числа. На этом предложи «Дальше по курсу». Для этой ветки не вызывай `course.py check` или `answer`.
