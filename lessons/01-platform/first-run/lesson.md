# Платформа Java. Первые 10–15 минут

К концу фрагмента студент может объяснить по результату эксперимента, зачем нужен каждый шаг цепочки `.java → javac → .class → JVM`, и различает назначение JDK, JRE и JVM.

Веди занятие в чате. Студент сохраняет изменения в IDE, агент выполняет команды и показывает реальные результаты. В одном сообщении давай один следующий шаг. Все команды ниже запускаются из корня курса.

## 1. Познакомься с проектом · 3–4 минуты

Начни с теории, как если бы студент впервые открыл проект. Назови тему и дай ссылку на `Main.java`. Покажи исходник и объясни, что `Main` — имя класса, `main` — точка входа в этот пример, а `System.out.println` печатает одну строку. Предварительных знаний о классах и методах для этого шага не требуется.

Дай карту первого запуска. `Main.java` — текст, который студент редактирует. Компилятор `javac` создаёт `Main.class` с байт-кодом, то есть инструкциями для JVM. Команда `java` запускает программу, а JVM загружает класс и выполняет его инструкции. Свяжи это с переносимостью: совместимые JVM на разных ОС могут выполнять один и тот же байт-код. Кратко объясни, что JDK содержит инструменты разработки и компоненты запуска, JVM выполняет программу, а JRE называют среду выполнения с JVM и стандартными библиотеками.

Предложи студенту найти в файле строку, которая пишет в терминал, и сказать «Запускай», когда он готов увидеть вывод. В первом сообщении остановись здесь.

## 2. Запусти первую версию · 2–3 минуты

Открой [Main.java](Main.java). Для первого прогона проверь, что он печатает «Первая версия». Создай отдельный каталог, чтобы результат сборки IDE не мог подменить контрольный класс.

```sh
mkdir -p .java-course/first-run/baseline
javac -encoding UTF-8 -d .java-course/first-run/baseline lessons/01-platform/first-run/Main.java
java -cp .java-course/first-run/baseline Main
```

Студенту покажи фактический вывод, коротко сообщи, что ты один раз скомпилировал и запустил программу. Предложи заменить строку «Первая версия» на «Вторая версия» в редакторе и сохранить файл. Спроси, что выведет **только повторный запуск** той же команды. Дождись прогноза и сигнала, что файл сохранён. Предлагай сначала сделать прогноз даже тогда, когда студент сразу просит запустить проверку.

Если контрольный `.java-course/first-run/baseline/Main.class` уже есть и выводит «Первая версия», используй его при возобновлении. Если контрольный класс отсутствует, а студент уже изменил исходник, приготовь стартовую версию из примера ниже во временной папке и скомпилируй её в каталог baseline. Оставь студенческий файл как есть.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Первая версия");
    }
}
```

## 3. Сравни прогноз с наблюдением · 2–3 минуты

Убедись по сохранённому `Main.java`, что строка изменилась. Если правку ещё не видно, попроси сохранить файл и подожди. После прогноза повтори ровно команду:

```sh
java -cp .java-course/first-run/baseline Main
```

Покажи вывод. Предложи студенту объяснить его. Если нужно, спроси, какой файл лежит в каталоге после `-cp`. Если ответ верный, попроси связать наблюдение с тем, что изменилось на диске.

После ответа объясни различие двух файлов. `javac` читает исходник `.java` и записывает `.class` с байт-кодом. `-cp` задаёт путь поиска классов. В этой форме запуска JVM загружает `Main.class` из каталога, заданного после `-cp`. При редактировании исходника сохранённый класс остался прежним.

## 4. Сделай так, чтобы запустилась вторая версия · 2–3 минуты

Спроси, какой шаг теперь нужен для нового вывода. Дождись ответа. Затем запусти `python3 course.py check first-run`. Эта проверка запускает `javac` и `java` во временной папке и фиксирует успешную сборку для перехода к вопросу. Покажи студенту точные команды из поля `commands` и вывод. При ошибке прочитай студенческий файл и дай подсказку по факту проверки.

На успешном результате предложи студенту сопоставить два действия эксперимента с инструментами, которые ты ввёл в начале. При желании студента покажи команды `java -version` и `javac -version`.

## 5. Проверь понимание · 1–2 минуты

Задай открытый вопрос из карточки `first-run`: что будет с запуском по имени класса и с повторной компиляцией, если удалить исходник и оставить собранный класс? Студент отвечает своими словами. Когда он объяснит обе части, зафиксируй прогресс через `python3 course.py answer first-run 0`. При неполном ответе спроси, какой вход нужен каждой команде.

Если при возобновлении `status` показывает `awaitingAnswer: true`, вернись к этому вопросу. Если студент менял код после успешной проверки, перед фиксацией ответа снова проверь текущий файл по его сигналу.

На этом фрагмент заканчивается. Предложи дальше посмотреть, что записано внутри `.class`, через `javap`.
